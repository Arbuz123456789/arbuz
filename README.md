### 1. Постановка задачи

> 


Данная задача сводится к нахождению количества уникальных длин сторон квадратов - то есть попарному сравнению длин сторон.

### 3. Выбор структуры данных

1. Анализ:
  Для хранения шести входных расстояний, которые необходимо будет сортировать и сравнивать, удобно использовать одномерный массив.

2. Структура данных:
  •  Одномерный массив типа int (или long, если ожидаются очень большие расстояния, но для натуральных чисел int обычно достаточно) для хранения шести расстояний.
  •  Переменная типа String для хранения результата ("YES" или "NO").

### 4. Алгоритм

#### Алгоритм выполнения программы:

1. Ввод данных:  
   Программа считывает шесть натуральных положительных числа – расстояние между точками.

2. Валидация ввода:
   Убедиться, что каждое введенное число является натуральным (больше 0). Если введено некорректное значение, вывести сообщение об ошибке и потребовать повторный ввод.
3. Хранение:
   Сохранить шесть чисел в массив distances (например, int[] distances = new int[6];).
4. Сортировка:
   Отсортировать массив distances по возрастанию.
5. Проверка на ромб:
  •  Шаг 1: Проверка сторон. Проверить, равны ли первые четыре элемента отсортированного массива: distances[0] == distances[1] && distances[1] == distances[2] && distances[2] == distances[3].
  •  Шаг 2: Проверка диагоналей. Проверить, равны ли последние два элемента отсортированного массива: distances[4] == distances[5].
  •  Шаг 3: Проверка на вырожденность. Убедиться, что первое расстояние (которое является минимальным после сортировки) больше нуля: distances[0] > 0. (Это условие, как правило, будет выполнено, если входные данные корректны, так как они натуральные).
  •  Шаг 4: Комбинация проверок. Если выполнены все три условия (первые четыре равны, последние два равны, минимальное расстояние > 0), то точки образуют ромб.
6. Вывод результата:
   Если все условия выполнены, вывести "YES".
   В противном случае, вывести "NO".

### 5. Программа
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int a = scanner.nextInt();
        int b = scanner.nextInt();
        int c = scanner.nextInt();
        int d = scanner.nextInt();
        int e = scanner.nextInt();
        int f = scanner.nextInt();
        int[] distances = {a, b, c, d, e, f};
        for (int i = 0; i < 6; i++) {
            for (int j = 0; j < 5 - i; j++) {
                if (distances[j] > distances[j + 1]) {
                    int temp = distances[j];
                    distances[j] = distances[j + 1];
                    distances[j + 1] = temp;
                }
            }
        }
        boolean sidesEqual = true;
        for (int i = 1; i < 4; i++) {
            if (distances[i] != distances[0]) {
                sidesEqual = false;
                break;
            }
        }
        boolean diagonalsEqual = (distances[4] == distances[5]);
        boolean diagonalsNotSides = (distances[0] != distances[4]);
        boolean allSame = true;
        for (int i = 1; i < 6; i++) {
            if (distances[i] != distances[0]) {
                allSame = false;
                break;
            }
        }
        if (sidesEqual && diagonalsEqual && diagonalsNotSides && !allSame) {
            System.out.println("YES");
        } else {
            System.out.println("NO");
        }
    }
}
```
